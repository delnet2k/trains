# Trains

Live Kelvedon ⇄ London Liverpool Street train times, served at <https://trains.delnet.co.uk>.

- Direct trains in each direction, including ones already on the way
- Track a train from where it starts to where it's going, updated every minute
- Station board for Kelvedon and Liverpool Street, arrivals and departures

Train times come straight from National Rail's Live Departure Boards on the [Rail Data Marketplace](https://raildata.org.uk/) in the visitor's browser; there's no server behind this page. The endpoints and Consumer Keys for the departure board, arrival board and service details products are set in `LDB` at the top of the train script in `index.html`.

This page is generated from a private project; don't edit `index.html` here by hand.
